## 📁 Assignments

### Assignment 1 - Exploring Prompt Engineering Techniques
Compared 6 prompting techniques (Zero-Shot, Role, Chain-of-Thought, Few-Shot, Instruction, Contextual) applied to AI Security thesis writing using ChatGPT. Found that **Instruction Prompting** produced the most complete and structured output.

### Assignment 2 - Gandalf Prompt Injection Challenges
Completed all 8 levels at gandalf.lakera.ai/baseline plus the extra CyberWarfare Labs LLM Vault Breach challenge. Techniques used ranged from direct requests to ASCII value extraction and JSON fragment attacks for the hardest levels.

### Assignment 3 - OWASP Top 10 LLM Labs
Completed 9 OWASP Top 10 LLM vulnerability labs on llm-sec.dev (LLM01–LLM08, LLM10) plus the HackAPrompt tutorial challenges, covering prompt injection, sensitive data disclosure, supply chain attacks, training data poisoning, improper output handling, excessive agency, system prompt leakage, vector/embedding weaknesses, and unbounded consumption.
