LLM02 / LLM07 · secret protection under decomposition

No single response leaks the secret.
The set of responses does.

This harness sends a target model a series of individually-innocuous questions — letter count, vowels, first/last letter, ASCII values — that a single-turn content filter would never flag. It then reconstructs the secret from the pieces and measures how much of it survives across four configurations: two model sizes × two guard strengths.

Method note

Each probe is sent as an independent, single-turn request — the model has no memory of prior probes. This demonstrates the leak works even without a sustained conversation: an attacker needs many short, disposable-looking queries, not one long jailbreak session. Leak strength is reported as an entropy estimate (bits of the secret still unknown) rather than pass/fail, because the vulnerability is fundamentally about information accumulation, not any single response crossing a threshold.
